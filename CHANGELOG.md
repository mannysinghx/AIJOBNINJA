# Changelog

All notable changes to AIJobNinja are documented here.

## 1.0.0 (2026-10-24)

First release of AIJobNinja.

### Features

* AI job search pipeline that runs inside your AI coding CLI: portal scanning, liveness checks, A-H evaluation reports with a 1-5 score, ATS-ready CV and cover letter generation, application tracking and follow-ups.
* Go terminal dashboard and an experimental local web UI for browsing the pipeline.
* Job Finder module (`modules/job-finder/`): portal CLIs for Jobindex, Jobnet, Jobdanmark, Akademikernes Jobbank, LinkedIn and freehire, a zero-dependency search UI, and a LaTeX application workflow.
