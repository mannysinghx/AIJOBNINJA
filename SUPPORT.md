# Support

| Need | Where |
|------|-------|
| **Setup help or a question** | Read [docs/SETUP.md](docs/SETUP.md) and [docs/FAQ.md](docs/FAQ.md), then open an [issue](https://github.com/mannysinghx/AIJOBNINJA/issues) |
| **Bug report** | Open an [issue](https://github.com/mannysinghx/AIJOBNINJA/issues) with the output of `node doctor.mjs` |
| **Feature idea** | Open an [issue](https://github.com/mannysinghx/AIJOBNINJA/issues) first, see [CONTRIBUTING.md](CONTRIBUTING.md) |
| **Security vulnerability** | Report privately, see [SECURITY.md](SECURITY.md) |

## Before opening an issue

1. Run `node doctor.mjs` and include its output.
2. Say which AI CLI you use (Claude Code, Codex, OpenCode, ...) and your OS.
3. Never paste your CV, profile or tracker contents: they hold personal data.
